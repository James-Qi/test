# T+0 稳定微 alpha 组合研究总纲

> Draft version: 0.1  
> Last updated: 2026-06-06  
> Project status: 研究方向重构 / 策略组合框架 / 后续批量探索基准  
> Note: 本文档用于沉淀从“单策略高年化”转向“T+0 稳定微 alpha 组合”的研究框架，后续可持续修订。

---

## 1. 研究背景

前期已经对多类 T+0 或近似 T+0 场内策略做过探索，包括：

- 30 年国债 ETF `511090.SH` / `511130.SH` 配对与类做市；
- 债券 ETF、政金债 ETF、货币 ETF 的低波动配对与执行研究；
- 可转债 ETF 官方 IOPV / 自算 IOPV / Level2 微结构研究；
- 港股互联网 ETF / 中证港股通互联网指数 `931637` 多 ETF 轮动；
- ETF 与国债期货、指数、官方 IOPV、自算 PCF、成分券估值之间的 lead-lag 与锚定关系；
- QMT / MiniQMT / PTrade 中的 3 秒 tick、Level2 十档行情、逐笔委托、逐笔成交、模拟盘 / 实盘状态机与执行日志。

前期单策略研究暴露出一个共同问题：

> 某些策略在理想回测中可以显示较高年化，但在真实盘口、价差、排队、延迟、撤单、部分成交、状态机约束和资金占用之后，单策略很难稳定达到 50%–100% 的账户级 alpha 年化。

因此，当前研究方向从“寻找单一高年化策略”调整为：

> 在所有可 T+0 操作的标的中，批量寻找可解释、可执行、扣除成本后仍为正、尾部风险可控的稳定微 alpha，通过多标的、多策略、低相关组合，累计账户级正收益。

---

## 2. 核心目标

本方向不再要求单个标的、单个策略具备极高年化，也不要求极高频交易。

新的核心目标：

1. **稳定正期望**：单策略只要在严格执行模拟后长期为正，即可进入候选池。
2. **低相关叠加**：多个小策略之间尽量来自不同品种、不同锚点、不同时间窗口、不同微观机制。
3. **不留隔夜仓**：所有策略必须在当日完成买入与卖出，不持有隔夜风险。
4. **持仓时间弹性**：0.x 秒、秒级、分钟级、几十分钟均可，只要净收益稳定、尾部可控。
5. **账户级累计收益**：最终关注账户级日均净收益 bp、账户级年化、回撤与收益稳定性，而不是孤立追求单策略持仓年化。

## 3. 指标体系

### 3.1 单策略指标

| 指标 | 含义 | 用途 |
|---|---|---|
| `gross_edge_bp` | 执行前毛收益 bp | 判断信号本身是否有价值 |
| `net_edge_bp` | 扣除全部执行摩擦后的净收益 bp | 判断策略是否可交易 |
| `trade_count` | 实际成交笔数 | 区分信号数与成交数 |
| `win_rate` | 单笔胜率 | 判断收益结构 |
| `avg_win_bp` / `avg_loss_bp` | 平均盈利 / 平均亏损 | 判断盈亏比 |
| `median_hold_seconds` | 中位持仓时间 | 衡量资金占用 |
| `positive_day_ratio` | 正收益交易日占比 | 衡量稳定性 |
| `max_daily_loss_bp` | 最大单日亏损 bp | 衡量尾部风险 |
| `max_consecutive_loss_days` | 最大连续亏损日 | 衡量心理与资金压力 |
| `t_stat_daily` | 日收益 t 值 | 粗略衡量统计显著性 |
| `parameter_stability` | 参数扰动后表现 | 判断过拟合风险 |

### 3.2 资金效率指标

| 指标 | 含义 |
|---|---|
| `capital_time_usage` | 资金时间占用率，约为 `sum(notional * hold_time) / (account_equity * trading_time)` |
| `holding_period_annualized_alpha` | 单位资金时间收益率，适合比较不同持仓时长的策略 |
| `account_daily_bp` | 对账户净值的日均贡献 bp，是组合层最重要指标 |
| `account_annualized_alpha` | `account_daily_bp * 252` 的近似年化口径 |
| `turnover_per_day` | 每日资金周转次数 |

### 3.3 组合指标

| 指标 | 含义 |
|---|---|
| `strategy_correlation` | 策略日收益相关性 |
| `cluster_drawdown` | 同一策略簇共同亏损情况 |
| `portfolio_daily_bp` | 全策略组合账户日均收益 bp |
| `portfolio_annualized_alpha` | 全策略组合年化 alpha |
| `portfolio_max_drawdown` | 组合最大回撤 |
| `tail_loss_95/99` | 95% / 99% 尾部单日损失 |
| `capital_conflict_ratio` | 多策略同时占用资金导致无法成交的比例 |

## 4. 持仓年化与账户年化的关系

持仓年化用于衡量单位资金时间的收益效率，但不能单独作为北极星指标。

设：

```text
net_pnl_i      = 第 i 笔交易净收益金额
notional_i     = 第 i 笔交易占用资金
hold_time_i    = 第 i 笔交易持仓时间
account_equity = 账户资金
T_day          = 每日可交易时间
```

则：

```text
holding_period_alpha ~= sum(net_pnl_i) / sum(notional_i * hold_time_i) * annual_trading_time
capital_time_usage   = sum(notional_i * hold_time_i) / (account_equity * annual_trading_time)
account_alpha        ~= holding_period_alpha * capital_time_usage
```

因此，单笔或单策略持仓年化很高并不代表账户年化高；只有当策略具备足够稳定的净收益、足够的可成交机会、合理资金占用和低相关叠加时，才能转化为账户级收益。

## 5. 策略准入标准

一个策略进入候选池，最低应满足：

1. 严格执行模拟后 `net_edge_bp > 0`；
2. 多数交易日不亏，或收益分布具有明确正偏；
3. 最大单日亏损不能显著大于长期日均收益；
4. 参数轻微扰动后仍保持正收益或接近正收益；
5. 不依赖未来函数，不使用真实交易时不可获得的数据；
6. 能用 QMT / MiniQMT / PTrade 的实际数据频率和字段实现；
7. 符合 T+0 当日买入、当日卖出、不留隔夜仓约束；
8. 与已有策略不应高度同源、同向、同亏损。

建议分级：

| 等级 | 日均账户贡献 | 稳定性 | 处理方式 |
|---|---:|---|---|
| A | `> 5 bp/day` | 多数日为正，尾部小 | 重点策略 |
| B | `2–5 bp/day` | 稳定但容量小 | 纳入组合 |
| C | `0.5–2 bp/day` | 稳定、低相关 | 保留观察 |
| D | 正收益但不稳定 | 需要过滤器 | 继续研究 |
| E | 执行后为负 | 暂停或仅保留信号研究 |

## 6. 执行模拟基准

所有策略尽量统一执行模拟口径，避免不同研究之间不可比较。

最低口径：

1. 不使用同拍成交；
2. 信号产生后至少使用下一拍 `bid/ask` 或下一拍 Level2 盘口成交；
3. 区分信号数、下单数、成交数；
4. 加入最小交易单位和资金占用；
5. 加入佣金、印花税、流量费等显性成本；
6. 对主动单使用盘口穿透模拟；
7. 对被动单使用排队成交概率或订单簿回放模拟；
8. 加入未成交、撤单、部分成交、单边暴露的处理；
9. 所有策略在收盘前强制退出，不允许隔夜残留。

进阶口径：

- 使用 `行情.csv` + `逐笔委托.csv` + `逐笔成交.csv` 重建订单簿；
- 将虚拟订单插入同价位 FIFO 队列；
- 估计不同价位、不同队列位置、不同盘口状态下的真实被动成交概率；
- 对策略结果输出成交概率敏感性矩阵；
- 将 Level2 回放结果与 QMT / PTrade 实盘小额采样日志交叉校准。

## 7. 重点策略族

### 7.1 ETF vs 估值锚偏离策略

可用锚点：

- 官方 IOPV；
- 自算 PCF 一篮子估值；
- 成分股实时估值；
- 期货价格；
- 指数价格；
- 汇率；
- 同类 ETF 均值；
- 高流动性 ETF；
- Level2 隐含公允价格。

候选品种：

- 港股 / 跨境 ETF；
- 恒生科技 / 港股互联网 ETF；
- 纳指 / 标普 / 日经 ETF；
- 黄金 / 商品 ETF；
- 可转债 ETF；
- 债券 ETF。

核心问题：

1. ETF 相对锚点偏离是否可回归；
2. 偏离幅度是否覆盖执行摩擦；
3. 偏离持续时间是否足以成交；
4. 偏离发生的时间窗口是否稳定；
5. 是否可横向复制到同类 ETF。

### 7.2 同指数 / 同资产 ETF 相对轮动

适合一组跟踪同一或高度相似指数的 ETF。

信号可以来自：

- 当前 ETF 相对组内均值的偏离；
- 相对 IOPV 溢价率偏离；
- 高流动性 ETF 领先低流动性 ETF；
- pair network 中稳定的领先 / 滞后路径；
- 多库存 grid 轮动；
- 只做历史胜率较高的方向。

该策略族已经在港股互联网 ETF 上形成原型，后续应复制到其他 T+0 ETF 家族。

### 7.3 特殊时段策略

重点研究：

| 时间窗口 | 可能 alpha 来源 |
|---|---|
| `09:30–09:45` | 隔夜信息、外盘、IOPV 延迟、开盘流动性不足 |
| `09:45–10:30` | 开盘错价修复、流动性恢复 |
| `13:00–13:15` | 午休后重新定价 |
| `14:30–14:55` | 收盘前流动性、调仓、资金行为 |
| 外部锚点跳变后 | 期货、汇率、外盘指数传导 |

该类策略不要求高频，只要求稳定正收益和严格风控。

### 7.4 Level2 微观结构策略

候选因子：

- bid/ask queue imbalance；
- 十档深度斜率；
- 大单挂出 / 撤单；
- 主动买卖冲击；
- 成交后短期反转；
- spread bounce；
- 流动性快速补单；
- 盘口厚度突变；
- 买卖盘压力持续时间。

预测目标可设置为：

- 未来 0.5 秒 / 1 秒 / 3 秒 / 10 秒 / 30 秒 mid 变化；
- 下一次 bid/ask 跳变方向；
- 被动挂单成交后不利选择概率；
- 是否适合挂被动买 / 被动卖；
- 是否应放弃交易或主动退出。

### 7.5 期货作为锚的 ETF / 现货策略

期货不一定作为主交易标的，也可作为锚点与过滤器。

| 期货锚 | 可过滤 / 定价对象 |
|---|---|
| TL / T / TF 国债期货 | 债券 ETF、国债现券、政金债 ETF |
| 股指期货 | 股指 ETF、跨境 ETF |
| 商品期货 | 商品 ETF |
| 黄金 / 原油期货 | 黄金 ETF、原油相关 ETF |
| 汇率 / 外盘期货 | QDII / 跨境 ETF |

目标不是预测大方向，而是在 ETF 或现货滞后时判断短期胜率是否改善。

## 8. 研究流程

### 阶段 1：候选扫描

按品种族和策略族批量扫描：

```text
T+0 标的池
  -> 估值锚候选
  -> 相对价格候选
  -> 特殊时段候选
  -> Level2 微结构候选
  -> 初步严格成本回测
  -> 稳定正收益候选列表
```

输出：

- `candidate_strategy_summary.csv`
- `candidate_strategy_daily.csv`
- `candidate_strategy_trades.csv`
- `candidate_strategy_report.md`

### 阶段 2：严格执行校准

对候选策略进一步使用 Level2 回放：

- next tick bid/ask；
- 10 档盘口穿透；
- 被动排队概率；
- 逐笔委托 / 成交订单簿回放；
- 撤单 / 部分成交 / 延迟成交模拟；
- 实盘小额采样校准。

### 阶段 3：组合层筛选

对通过执行口径的策略计算：

- 日收益相关性；
- 同亏损日分布；
- 资金时间冲突；
- 标的和策略簇暴露；
- 账户级收益曲线；
- 组合最大回撤；
- 单日止损规则。

### 阶段 4：小资金实盘验证

实盘验证只用于确认：

- 成交概率；
- 排队位置；
- 撤单延迟；
- 状态机稳定性；
- 账户资金占用；
- 真实日志与回放模型差异。

不应在理论期望不足时贸然实盘。

## 11. 研究原则

1. 不因单策略年化不高而直接否定，只要稳定正收益、低相关、可执行，就有组合价值。
2. 不接受理想化成交收益，所有候选必须进入严格执行模拟。
3. 不把持仓年化作为唯一指标，必须同时看账户级日均 bp 和资金时间占用。
4. 不追求强行提高交易频率，低频稳定机会也应保留。
5. 不把同源策略机械相加，必须计算相关性和共同亏损。
6. 不留隔夜仓，收盘前必须清仓或强制退出。
7. 每个策略都要能解释收益来源，避免纯参数拟合。
8. 每次新增数据、脚本、结果，都应能通过 `docs/data_manifest.csv`、结果目录和研究文档复现。

---

## 12. 当前结论

当前研究方向应正式从：

```text
单策略高 alpha 年化
```

调整为：

```text
T+0 多标的、多策略、稳定微 alpha 组合
```

这一路径更符合现有数据、工具、资金规模和交易偏好。它允许单个策略低频、低收益，但要求每个策略扣除真实执行摩擦后仍具备稳定正期望。最终通过多个低相关策略在账户层面叠加，形成更平滑、更现实的账户级正收益曲线。
